## 🚀 Featured Projects

<details open>
<summary><strong>🌐 1 · Portfolio & Blog App</strong> — <a href="https://portfolio-and-blog-app-fontend.vercel.app/">Live Demo ↗</a></summary>
<br/>

> **Stack:** Vue.js 3 · Tailwind CSS · Axios · Vue Router · Laravel REST API · MySQL · JWT · Vercel · Railway · Aiven

A fully decoupled full-stack platform. The admin dashboard manages projects & blog posts. Visitors browse via a Vue.js SPA communicating exclusively through a Laravel REST API backend with Aiven cloud MySQL.

**✅ Key Achievements:**
- JWT-secured API with **role-based access control** separating admin and visitor capabilities
- Deployed across **3 platforms**: Vercel (frontend) · Railway (backend) · Aiven (cloud MySQL)

**🔧 Engineering Challenges Solved:**
- CORS errors from Vercel → Railway fixed via Laravel CORS middleware with explicit origins
- Silent logout from expired JWTs fixed with **Axios interceptors** detecting 401s and auto-refreshing
- Vue Router history mode 404 on Vercel page refresh fixed via `vercel.json` rewrite rules
- Aiven MySQL SSL failures resolved by setting PDO SSL cert options in Laravel config

</details>

> **Stack:** Laravel MVC · PHP · MySQL · Blade · Bootstrap 5 · JavaScript · Role-Based Auth · File Uploads

- Full job application workflow: listing → filtering → applying → status tracking → admin review

**🔧 Engineering Challenges Solved:**
- N+1 query problem on job listings solved with **Eloquent eager loading** (O(n) → fixed DB calls)
- File upload failures fixed by resolving storage symlink + configuring correct disk driver
- Employer routes exposed without auth fixed by wrapping in dedicated middleware group

> **Stack:** Laravel 11 · PHP 8.3 · Tailwind CSS · Alpine.js · Vite · MySQL · Repository Pattern · CSRF

Production-ready platform closing the information gap in Bangladesh's agricultural trading sector. Field agents log prices from regional markets; traders identify arbitrage opportunities in real time.

**✅ Key Achievements:**
- Real-time smart dashboard with **average price tickers** and market trend indicators
- Compare module for visualising **price disparities** across regional divisions
- **Repository Pattern** architecture for clean separation of business logic

**🔧 Engineering Challenges Solved:**
- SQL degradation on large datasets resolved via Eloquent eager loading + date-range query scopes
